# src

Open tabs move onto a newer build automatically via the build-watchdog module-script signature; the dev server stamps the page with the newest source change time so an already-open preview tab reloads onto edited code, and dev tooling scripts are excluded from the signature.
- External inventory valuations use the shared server-side inventory-valuation helper, combining verified profiles with configured assumptions and explicitly reporting missing rates and reconciliation differences; share visibility gates remain authoritative.
- The installed Load Reports app is locked per window by launch address to Load Reports, Container Loads and sign-in; it is a device UI lock, not a permission, so browser tabs keep the full portal.
- Orders portal (/orders, Inbox → Orders portal): customers hold a secret per-conversation link and reach order_portal_* data and the private order-portal bucket only via the orders-portal function; staff use is_staff RLS, so it works without Outlook and never exposes other conversations.
- Orders portal attachments open in the shared in-app OrderFileViewer from fetched data (PDF pages drawn as images; blob links for download), never by navigating to storage addresses, because browser blockers refuse those pages.
- Inbox and Orders portal tab badges count what is in each inbox (unfiled email threads, orders not done) and put unread numbers in the tooltip, because synced email leaves thousands of threads unread so an unread-only badge would be permanently maxed out.
- Waste names/EWCs follow the agreed standard in waste-streams (data in waste-stream-standard.json): screens resolve recorded wording to the standard name at display time and stored job wording is never bulk-rewritten, because rebate filters and past reports match on it; portal EWC corrections set waste_corrected_at so Data Uploads keep them. New bookings, weighbridge price lines and Duty of Care products are chosen from the standard list (WasteStreamPicker) and wording carried into a new booking goes through standardBookingWaste, so non-standard names cannot re-enter. Screens show each stream's agreed reference code with WasteRefChip/WasteRefFor so staff can cross-check codes between systems. Rate-card lines priced by grade or covering several streams resolve to no stream and leave the waste for staff to choose. Haulage Only is the haulage_only Route One job type (no waste/EWC), not a waste choice; new configured job-type keys need a matching route_one_job_type database value or bookings of that type cannot save.
- Admin → Apps is the single home for installable app cards; the Office App card/guide read OFFICE_APP_TILES so listed features never drift from the launcher.
- Installable apps share the W1 home-screen icons (w1-icon-192/512, apple-touch-icon); app pages offer AddToHomeScreenButton, which uses one-tap install when offered and otherwise shows browser-specific steps, sending in-app viewers and framed pages (e.g. the editor preview) to open the app on its own because they cannot install; app cards carry a QR code so phones open the link in their normal browser.
- Office App Skip Tracker and Contaminations reuse the Driver App components with reporter type "office" (signed-in staff); driver-actions contamination_config also accepts a staff session, so office reports land in the same skip tracker and contamination records as drivers.
- Office App remembered sessions are kept current from the auth listener (session keys rotate on refresh), sign-in calls time out with a retry message, and a full portal password sign-in clears the Office App lock, so a device never sticks on a sign-in screen.
